Doc Drift for Confluence and Jira

Doc Drift tells you when a Confluence page has drifted from the Jira work it describes: the work items it mentions were finished, dropped (won't do, duplicate, declined), re-scoped or removed after the page was last edited. It shows a verdict on every page, a ranked report for each space, the pages that mention a work item from inside Jira, and a Rovo agent and MCP tools that answer the same questions.

Support

Questions, bugs and feature requests: open an issue at github.com/mertbatis/kronides-apps/issues. We aim to answer within two business days.

Setup

  1. Install the app in Confluence and in Jira on the same site.
  2. On any page, open Doc Drift under the page title to see whether the work items it mentions changed after the page was edited, and use Ask for a review to add a comment listing what changed.
  3. In a space, open Doc Drift in the space sidebar for the ranked report.
  4. In Jira, open Pages about this work item on a work item.
  5. Rovo: choose the agent Doc Gardener and ask "Which pages in this space are out of date?".

Privacy policy

Last updated: 16 November 2026

Doc Drift runs entirely on Atlassian Forge ("Runs on Atlassian"). It has no servers of its own and sends no data outside Atlassian.

  • What the app reads: Confluence pages (title, body, version date and editor) and the Jira work items they mention (summary, status, resolution and change history), always with the permissions of the user asking.
  • What the app changes: only when a user presses "Ask for a review", it adds one footer comment to that page. Nothing else is changed.
  • What the app stores: nothing. Results are computed on request.
  • Sharing: none. No analytics, no third-party services, no outbound network access, and no language model is called by the app itself.
  • AI: the Rovo agent and MCP tools return the same facts the app shows; the language model is Atlassian Rovo, operated by Atlassian under your Atlassian agreement.
