Answer Atlas for Jira

Answer Atlas helps support teams answer repeat requests. On a new request it finds resolved requests in the same project that asked the same thing, picks the reply that actually solved each one, and turns it into a draft for the new requester. An agent reviews, edits and sends it as a reply or saves it as an internal note. A Rovo agent (also available to external AI agents through MCP) answers "has this been asked before?" and "what do people ask most?".

Support

Questions, bugs and feature requests: open an issue at github.com/mertbatis/kronides-apps/issues. We aim to answer within two business days.

Setup

  1. Install the app in Jira. It works best in Jira Service Management projects with a history of resolved requests.
  2. Open a request and expand the Answer Atlas panel (or add it from the app button on the request).
  3. Review the earlier answers, press Use this answer, edit the draft and press Send to customer or Save as internal note. Sending uses your own Jira permissions.
  4. Rovo: open Rovo chat and choose the agent Answer Atlas. The agent is read-only.

Privacy policy

Last updated: 14 November 2026

Answer Atlas runs entirely on Atlassian Forge ("Runs on Atlassian"). It has no servers of its own and sends no data outside Atlassian.

  • What the app reads: summaries, descriptions, reporters, dates and comments (with their public/internal visibility) of resolved requests in the project of the request being viewed, using the permissions of the user who is viewing.
  • What the app changes: only what an agent explicitly sends: one reply or internal note on the current request.
  • What the app stores: a reuse log (request key, the request the answer came from, whether it was internal, the account ID of the agent, and the time) and a per-project reuse counter, in Forge storage inside your Atlassian site, limited to the latest 200 entries.
  • Sharing: none. No analytics, no third-party services, no outbound network access. Similarity is computed inside the app; no request text is sent to any language model by the app itself.
  • AI: the Rovo agent and MCP tools are read-only and return the same facts the panel shows; the language model is Atlassian Rovo, operated by Atlassian under your Atlassian agreement.
  • Deletion: uninstalling the app deletes its stored data according to Atlassian Forge's data lifecycle.
