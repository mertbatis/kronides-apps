Upstream for Jira

Upstream answers "will the work I depend on land in time?". For a work item it walks the "is blocked by" chain in any project, compares due dates and release dates, forecasts the earliest finish, shows the critical path and flags upstream work that is late, overdue, undated, unassigned or not started. A project page lists every blocked item and the teams you are waiting on. The same analysis is available as a Rovo agent and an MCP tool.

Support

Questions, bugs and feature requests: open an issue at github.com/mertbatis/kronides-apps/issues. We aim to answer within two business days.

Setup

  1. Install the app in Jira.
  2. Open a work item with "is blocked by" links and expand the Upstream panel (View app actions → Upstream).
  3. Open a project's Dependency risk page from the project navigation.
  4. Rovo: choose the agent Upstream and ask "Which items in WEB will slip because of dependencies?".

Privacy policy

Last updated: 17 November 2026

Upstream runs entirely on Atlassian Forge ("Runs on Atlassian"). It has no servers of its own and sends no data outside Atlassian.

  • What the app reads: work items (summary, status, due date, fix versions, assignee, project, Team field and issue links), always with the permissions of the user who is asking.
  • What the app changes: only when a user presses Ask for a date, it adds a comment, as that user, on the upstream work item.
  • What the app stores: nothing. Results are computed on request.
  • Sharing: none. No analytics, no third-party services, no outbound network access, no language model called by the app; the Rovo agent uses Atlassian Rovo under your Atlassian agreement.
